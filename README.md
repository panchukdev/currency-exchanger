
# Currency Exchange Web App

A simple real-time currency converter web application built with Node.js, Express.js, and Axios using the ExchangeRate API.



## Features

- Real-time currency conversion
- Supports multiple currencies
- Simple and clean UI
- Server-side rendering with EJS


## Tech Stack

**Client:** EJS (templating engine)

**Server:** Node.js, Express.js, Axios, ExchangeRate API


## Installation

1. Clone the repository
```bash
  git clone https://github.com/panchukdev/currency-exchanger.git
  cd currency-exchanger
```
2. Install dependencies
```bash
npm install
```
3. Create .env file
```env
API_KEY=your_api_key_here
```
👉 You can get your API key from:
https://www.exchangerate-api.com

4. Run the project
```bash
node index.js
```
